## 1. 문제 정의

씬파일러(Thin-Filer)는 금융거래 실적이 적어 불리한 신용평가를 받는 '금융 이력 부족자'를 말한다. <sub>국내 금융거래 고객 약 4,800만 명 중 약 1,300만 명(27%)으로 추정 — 2019 나이스평가정보</sub>

이들은 점수가 낮게 나오는 것이 아니라, **점수를 산출할 근거 자체가 없다.** '이력 없음 = 판단 근거 부족'이라는 이유로 거절되거나 높은 금리를 감수하게 된다.

### 진짜 난제는 모델이 아니라 채점이다

> **등급은 매길 수 있지만, 그 등급이 맞는지 확인하는 건 별개의 문제다.**

씬파일러는 대출을 받은 적이 없으니 연체도 관측되지 않는다. 점수를 내도 대조할 정답(라벨)이 없다. 기존 해법은 두 가지뿐이다 — 실제로 대출을 집행하고 1~2년 후 성과를 확인하거나(시간·비용), 거절 추론(Reject Inference)으로 성과를 **추정**하거나.

**이 프로젝트의 시도**: 추후 정답이 생긴 **이탈 집단**을 찾아, 추정이 아닌 **실측**으로 소규모 채점을 시도하고, 그 과정 전체를 공개 데이터로 재현 가능하게 정리했다.

## 3. Track A — 실제 연체 라벨로 채점

### 3-1. 씬파일러 재정의와 모집단 선정

기본 5필드(3/6/12개월 전 신용카드 기관수, 카드·대출 건수 전부 0)만으로는 "지금 없음"밖에 담지 못했다. **엄격 3필드**(최초 카드·대출 개설 경과일, 연체건수 = 0)를 추가해 "지금도 없고 과거에도 없었다"로 재정의했다. 2022년 기준 **333,571명**.

모집단 선정은 두 번 실패했다.

| 시도 | 결과 | 판정 |
|---|---|---|
| 기본 정의로 연체 예측 | 양성 4,668건 — 과거 연체 이력자 다수 포함 | ❌ |
| 엄격 정의로 연체 예측 | 양성 269건(0.02%) — 92%가 2019년 편중 | ❌ |
| **신규 신용 진입자 연체 예측** | 작년 씬파일러 → 올해 카드·대출이 생긴 68,677명, **양성 144건(0.21%)** | ✅ |

타겟: 신청일로부터 12개월 내 30일 이상 연체 경험 여부

### 3-2. 변수 선정 — 4단계 필터, 157개 → 10개

`사전 차단`(정의 8필드·연체 계열·대출 후 거래 데이터 제외) → `커버리지`(정보없음 96%↑ 및 상수 변수 제거) → `정보가치(IV)` → `모델 기여 검증`

**채택 (10개)**

| 계열 | 채택 근거 |
|---|---|
| 생활이력 3년 누적 (3) — 주소·직장·휴대폰 변경 이력 | 신용거래가 없어도 생기는 정보 |
| Δ생활이력 최근 1년 (3) | 패널 구조 활용 파생. 주소는 1년 IV 0.419 > 3년 누적 0.364 |
| 자산·거주지 시세 (3) | IV 상위 대표만 선별 |
| 현거주지 평형 (1) | '정보없음'도 독립 범주로 유지 — 정보의 부재 자체가 신호 |

**폐기**

- **국민연금·건강보험 성실납부** — 기획 단계에서 가장 기대했던 변수였으나 진입자 68,677명 **전원 결측(100%)**
- **자산계열 7종 중 4종** — 양성 144건 대비 차원 과다, 변수를 늘리자 성능이 0.62에서 0.57로 하락
- **가격 × 신뢰수준 결합 파생** — IV 0.46~0.66으로 높았으나 모델 기여 0

### 3-3. 불균형 대응

연체가 0.2%면 전부 정상이라고 찍어도 정확도 99.8%가 나온다. 정상치를 솎아내 비율을 맞추는 학습이 필요했다.

| 방법 | AUROC |
|---|---|
| **음성 다운샘플 + 5앙상블** | **0.821 (채택)** |
| SMOTE (오버샘플링) | 0.722 (이득 없음) |
| 가중치 (scale_pos_weight) | 0.713 |
| 차원축소(PCA) 병행 | 이득 미미 |

### 3-4. 결과

| 모델 | AUROC | 95% CI |
|---|---|---|
| *(참조)* CB 완전정보 | *0.990* | — |
| A2 — 인구변수 포함 | 0.819 | [0.783, 0.852] |
| A2 — 성별만 제외 | 0.793 | [0.756, 0.828] |
| **A2 공식 — 인구변수 전부 제외** | **0.690** | **[0.646, 0.731]** |

**0.990은 자랑이 아니라 경고다.** 연체 예측에 연체 이력을 넣었을 때의 수치이고, 해당 필드들을 사전 차단한 이유의 근거다.

**공식 수치로 가장 낮은 0.690을 채택했다.** 성별 제외로 0.026, 연령 제외로 0.103을 잃었다. 차별 방지와 공시 관행을 지키기 위해 **성능을 대가로 규범을 택한** 선택이다. 그럼에도 신뢰구간 하한이 0.5를 상회한다.

등급 산정은 **ChiMerge**(위험도가 실제로 달라지는 지점에서만 분할). SHAP 기여 1위는 현거주지 평형(35.1%), 다음이 거주지 매매가(15.9%)·전세가(13.2%)였고 생활이력 계열이 약 22%를 차지했다.

## 4. Track B — 라벨 없는 집단을 채점하는 법

### 4-1. 구조 전환

씬파일러 정의 5필드(신용카드 건수, 대출 건수, 3·6·12개월 전 신용카드 기관수 전부 0) 기준 **13.37%(2021) / 12.53%(2022)**.

타겟 설정은 세 번 실패했다.

| 시도 | 결과 | 판정 |
|---|---|---|
| 연도 간 변화 비교 | 연체 필드 악화 113명(0.256%) — 표본 부족 | ❌ |
| 기존 신용점수 등급화 | 동일인 점수가 1년 새 86.41% 변동 — 불안정 | ❌ |
| 최장연체일수 이진화 | 씬파일러 정의 수정 과정에서 폐기 | ❌ |
| **1년 내 연체 발생 필드 채택** | 신용이력보유군 양성 약 4.23% | ✅ |
| **시점 분리 재설계** | 정의는 2021년, 타겟은 2022년 발생분 | ✅ 최종 |

→ **신용이력보유군에서 학습·검증하고, 씬파일러에는 점수만 매기는 구조**로 전환했다.

### 4-2. 변수 선정 — 738개 → 69개

```
738        723        358         59         46    →    69
전체후보 → 사전차단 → 커버리지 → 정보가치(IV) → 중복처리 → 최종
```

| 단계 | 변수 수 | 검증 AUC | PR-AUC |
|---|---|---|---|
| 시작 | 46 | 0.7782 | 0.1772 |
| 소비 카테고리 33개 시도 → 12개 채택 | 58 | 0.7794 | 0.1780 |
| **소비구성비 33개 시도 → 11개 채택** | **69** | **0.7824** | **0.1820** |

알고리즘은 PR-AUC 기준으로 XGBoost 채택 (CV 0.2550 / Test 0.2660, LogisticRegression 0.1220/0.1230, RandomForest 0.2210/0.2200). CV와 Test 격차가 작아 과적합 징후 없이 재현됐다. 등급은 균등 분위에서 **ChiMerge**로 전환했다.

### 4-3. 컷오프별 운영 기준

| 컷오프 | 위험군 비율 | 정밀도 | 재현율 |
|---|---|---|---|
| 전원 | 100% | 4.23% | 100% |
| 5등급 이상 | 23% | 13.38% | 72.25% |
| **9등급 (최고위험만)** | 1% | **50.17%** | 11.87% |

넓게 보려면 5등급 컷오프, 정밀하게 보려면 9등급. **정답은 하나가 아니라 우선순위에 따른 선택이다.**

### 4-4. 이탈 코호트 — 실측 채점

**씬파일러 정의에서 벗어난 사람들**을 추적했다. 2021년 3월에 씬파일러였으나 2022년 3월에는 아닌 사람 — 그 사이 금융거래를 시작한 집단이다. 이들에게는 **씬파일러 시절의 대안정보**와 **이후 발생한 실제 연체**가 동시에 존재한다.

```
5개 정의 필드를 두 시점(202103 / 202203) 비교
  → 이탈 코호트 3,087명 탐지
  → 정의 시점 불일치 오염 607명 제거
  → 정제 코호트 2,931명 (실제 연체 39명)
```

202103 시점 변수로만 점수를 산출하고 202203에 관측된 연체로 채점했다. 정보 누출이 구조적으로 불가능한 설계다. 검증에는 최종 69개 변수에서 인구통계 3계열(연령·직업유형·거주지역)을 제외한 **66개**를 사용했다.

**동일 코호트 2,931명 채점 결과**

| 투입 정보 | AUC | 95% CI | 우연일 확률 |
|---|---|---|---|
| 기존 신용정보 26개 | 0.5265 | [0.43, 0.62] | 약 30% (297/1000) |
| **대안변수 66개** | **0.7739** | [0.70, 0.84] | **0.1% 미만 (p<0.001)** |

기존 신용정보 모델은 **95% CI가 0.5를 포함한다.** 동전 던지기와 구분되지 않는다는 뜻이다. 씬파일러에게 기존 신용정보가 작동하지 않는다는 것을 성능 저하가 아니라 **통계적 무효**로 확인했다.

변별력(표준편차) 기준 상위 변수는 **휴대폰번호 변경 이력(0.2395)**, 총자산 증감률(0.1854), 총자산(0.1669), 방송 관심도(0.1540) 순이었다.

## 5. 검증 과정에서 걸러낸 것

> **"성능이 급등하면 좋아하지 않고 의심했습니다. 실제로 두 번 다 순환논리였습니다."**

### 정보가치(IV)가 높다고 해서 쓰지 않았다
'신용카드 총한도금액' 등의 IV가 높은 것은 **카드·대출이 많으면 연체도 자연히 많아진다**는 당연한 구조 때문이었다. 노출 관련 필드 40개를 제외하니 최상위가 정상화됐다.

### 성능이 튀면 의심했다
카드소비금액 두 변수를 실수로 후보에 포함시켰을 때 AUC가 0.7824에서 0.8476으로 급등했다. 성과로 기록하지 않고 역추적해 **순환논리임을 확인하고 제외**했다.

### IV 계산 버그
값의 절반 이상이 0에 몰린 분포에 `qcut`을 그대로 적용하면 구간 경계가 붕괴한다. **0 여부를 먼저 분리한 뒤 나머지를 나누도록** 함수를 고쳐 재계산하니, 잘못 탈락했던 **변수 6개가 새로 통과**했다.

### 미리 줄이는 것이 항상 옳지는 않다
IV로 미리 걸러냈던 소형유통점 소비 변수가 이후 강한 신호로 재발견됐다.

### SHAP 상수 오프셋 함정
`mean|SHAP|` 1위는 `DAR`(자산대비 부채, 0.4608)이었으나 **씬파일러의 98.9%가 이 값이 0**이었다. 전역 중요도는 높아도 씬파일러 내부 변별력은 없는 상수 오프셋이다. 표준편차 기준으로 재평가해 실제 1위를 가려냈다.

### PCA 폐기
파생변수 161개를 압축하려 했으나 주성분 30개로도 누적 설명분산이 53.3%에 그쳤다. 각 변수가 서로 다른 소비 카테고리를 재고 있어 공통 축으로 묶이지 않았다 — 개별 IV 선별로 전환했다.

### 데이터 구조 검증
Sheet11이 8개 분기 파일로 제공되나, 실제로는 **연도별 스냅샷 2개가 4회씩 중복 저장된 구조**였다. 분기 시계열로 오인했다면 전체 분석이 무너질 지점이었다.

## 9. 한계 — 이 프로젝트가 주장하지 않는 것

**① 합성데이터**
실제 개인정보 대신 통계적 특성만 반영해 만든 데이터다. 산출물은 완성 모델이 아니라 **재현 가능한 과정**이다.

**② 확인 범위의 한계**
확인된 것은 엄밀히 **"신용 획득에 성공한 씬파일러 출신"**에 관한 것이다. 씬파일러로 남아 있는 사람들의 점수는 여전히 추정이다.

**③ 정답 표본의 부족**
맞혀야 할 실제 연체자는 Track A 144건, Track B 39건이다. 표본이 작으면 성능 수치가 크게 흔들리므로 **항상 신뢰구간과 함께** 제시했다.

**④ 산출 점수 ≠ 연체 확률**
불균형 대응 학습(다운샘플 50:1) 특성상 점수 절대값이 부풀려져 있다. **순위·등급 비교 용도로만 유효**하며, "9등급 = 연체 확률 90%"처럼 읽을 수 없다.

**⑤ 두 트랙은 서로를 검증하지 않는다**
데이터·대상·정답의 정의가 모두 다르다. 방향이 일치한다는 점만 확인했다. **관찰이지, 증명은 아니다.**

## 10. 결론

두 트랙 모두 **대출 집행 없이 정답을 만들어 채점**했다.

| | Track A | Track B |
|---|---|---|
| 신호 확인 | 모델 성능 0.690, 하한도 0.5를 상회 | 기존정보는 찍기 수준 → 대안변수 66개로 0.774 |
| 같은 변수 지목 | 생활이력 계열이 상위 기여 | 휴대폰 변경 이력이 단독 1위 |
| 확인 못한 것 | 씬파일러 잔류자 등급은 추정치 | 동일 |

이 관찰은 세 방향으로 이어진다.

- **CB사·금융사** — 대출 전에 등급 신뢰도를 미리 가늠해 볼 근거
- **씬파일러** — 이력이 없어도 평가받을 여지
- **방법 자체** — 정답이 없어 검증이 막힌 다른 문제에 적용

표본이 적었던 이 프로젝트와 달리 CB사는 같은 설계를 훨씬 큰 규모로 운용할 수 있다. 양성 표본이 커지면 신뢰구간이 좁아지고 연령·소득대별 층화도 가능해진다.

## 12. 협업 규칙

- **데이터 원본은 커밋하지 않는다.** `.gitignore`로 차단되어 있으며, 저장소의 CSV는 모델 산출물에 한한다.
- **`main` 직접 커밋 금지.** 작업 브랜치 생성 후 PR로 병합한다. (예: `track-b/eda`, `docs/변수사전`)
- 작업 시작 전 `git pull`.
- 커밋 메시지 형식: `[전처리] 씬파일러 식별 로직 추가`
